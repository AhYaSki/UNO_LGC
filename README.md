# UNO_LGC

A custom Java-based implementation of the classic UNO card game.

## Features

- Full gameplay logic for UNO
- Custom UI components using `UFrame`, `UButton`, `UCard`, and others
- Turn-based card playing mechanics
- Special action cards (Skip, Reverse, Draw Two, Wild, etc.)
- Win detection and game reset functionality
